# Granite & Heavy Transport Management System

## 📌 Project Description
The Granite & Heavy Transport Management System is a menu-driven C project designed to manage heavy vehicles, transportation trips, and routes between different locations.

## 🎯 Objectives
- Manage vehicle details.
- Add and display transport trips.
- Search vehicles using vehicle ID.
- Find routes between locations.
- Demonstrate data structures using C.

## 🛠️ Technologies Used
- **Language:** C
- **Data Structures:** Graph, Binary Search Tree (BST), Linked List
- **Algorithm:** Breadth-First Search (BFS)
- **Compiler:** GCC / Code::Blocks

## ✨ Features
1. Add new vehicles.
2. Display all vehicle details.
3. Search vehicles by ID.
4. Add transportation trips.
5. Display trip records.
6. Find routes between predefined locations.
7. Check vehicle load capacity.

## 🧠 Data Structures
- **Graph:** Represents locations and their connections.
- **BST:** Stores and searches vehicle records using vehicle IDs.
- **Linked List:** Maintains transportation trip records.
- **BFS:** Finds routes with the fewest connections.

## ▶️ How to Run

Compile the program:

```bash
gcc granite_transport.c -o granite_transport
```

Run on Windows:

```bash
granite_transport.exe
```

Run on Linux/macOS:

```bash
./granite_transport
```
